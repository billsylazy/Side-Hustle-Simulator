# Icon checklist — all screens (merged)

**22 distinct icons to upload**, from the gvesster *Free Icon Pack v3.1 (Basic)*.
Until uploaded, icon slots render blank (`rbxassetid://0`).

## How to upload

1. In Roblox Studio: **View → Asset Manager → Bulk Import**, pick the 256px files below.
2. Right-click each uploaded image → **Copy Asset ID**.
3. Paste the ids back to Claude as `icon name = id` lines to get every `.rbxmx` rebuilt
   with the ids baked in (one list fills all six screens).
